# AuraShades

**What it is:** a freemium library of live WebGL shader backgrounds (gradient, grain, pastel, aurora, dither, ASCII, grid, light, liquid, texture) for product websites. Browse, tune palette and motion, copy as a React component, raw GLSL, or CSS palette.

**Who it is for:** front-end developers and designers building marketing sites, product launches and portfolios who want living backgrounds without writing shaders.

**Main action:** Browse the library (free), then upgrade to Pro for the full set and React components.

**Plans (assumed, to confirm):** Free (10 shaders, one per style, GLSL + CSS copy), Pro $12/mo or $96/yr (all shaders, React components, commercial licence), Team $36/mo (5 seats, shared palettes).

**Surface modes:** Landing and pricing = Persuade. Library = Experience. Editor = Operate. Docs = Read.

**Look:** dark-first (shaders glow on a dark stage), light mode supported. No violet in the brand chrome; the shaders themselves carry colour.
